# AGENTS.md — Đảo Đèn Lồng

3D third-person game (Three.js in browser) + headless simulation (Node), graded by Test Contract **v1.2** (3 nights, lantern fuel, win = survive to dawn with ≥ 60% lit).

## Commands
- Install: `npm install` (only dependency: three@0.160.0)
- Play: `npm start` → http://localhost:8080 (`?autostart=1&night=N&seed=S&bot=1&warp=T&screen=intro|pause&pitch=&dist=&fps=1` for scripted views)
- Test (unit + contract + scenarios): `npm test`
- Headless: `node src/headless.js --seed 1 --night 1|2|3 --ticks 600 --out out.jsonl [--scenario f] [--inputs f] [--snapshot-every N]`
- Evidence: `npm run proof -- phase-N` → `docs/proof/phase-N/` (skill: `.claude/skills/verify/SKILL.md`; run from PowerShell on Windows)

## Layout
- `src/sim/` pure deterministic logic, no DOM, no `Math.random`, no `Date`. `game.js` rules, `maps.js` 3 standard maps (terrain height fn, spawn points, lanterns, pads, charms), `constants.js` standard numbers without a contract key, `bot.js` autopilot (evidence only).
- `src/headless.js` CLI per contract. `src/web/` render/input/audio/UI only — never changes rules.
- `game.contract.json` = tuning source; sim reads it. Never hard-code tuning elsewhere.
- `tests/scenarios/*.json` are generated by `python tests/gen_scenarios.py tests/scenarios` — edit the generator, not the JSON.
- Requirements: `docs/lab/ticket-0N.md` (verbatim). Notes: `docs/notes/phase-N.md`. Design decisions: `docs/adr/`. Breaking changes: `CHANGELOG.md`.

## Rules
- The ticket text is the authority. Quote it; do not invent requirements. Unclear → assumption row in `docs/notes/phase-N.md`.
- Tick order is mandatory (ticket-02 §"Thứ tự xử lý"): input/pause → counters → player move + fall → pickup → interact → safe zone → pulse → shades/drifters move → collisions (drifters, then shades by id) → spawns → win/lose → snapshot.
- Event tick = tick after the step. Timers are countdowns decremented in step 2; spawns use `sim_tick`.
- Every new rule gets a scenario with hand-computed expectations written in `requirement` (never copied from output). Mutate a number once to confirm the test fails.
- A ticket that replaces a rule: change the old scenario and log old→new + reason in the phase notes. Never delete or skip silently.
- Creative extras render-only (src/web) so headless output is unchanged.
- Shade states only: spawning, wander, chase, recoil, stunned, drain. Drifter: idle, chase, flee, removed.
- Lantern fuel is an integer in 1/60 units (`fu`, max 6000); round only on output. Safe zone = `lit && fu >= 1800` (derived, never stored). Capacity is derived from `successfulLights`.
- A change request that replaces rules needs: ADR in `docs/adr/`, breaking-change list in CHANGELOG, old→new test table in phase notes.
- No code comments unless asked. No new dependencies without a reason in notes.
- Do not finish while `npm test` is red (Stop hook enforces this).
